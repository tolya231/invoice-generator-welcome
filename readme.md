# invoice-generator-welcome

Welcome page for the Invoice Generator Chrome extension. Opens once, right after
install, and covers the two steps that decide whether the extension gets used:
pinning it to the toolbar and filling in the business details it prints on every
document.

The step images are rendered from the extension itself — see
`invoice-generator/store/screenshots/welcome/` in the extension repository — so
they stay in step with the product instead of ageing into a different interface.
